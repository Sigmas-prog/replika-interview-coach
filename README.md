# Реплика

Персональный тренажёр собеседований для IT-специалистов. Пользователь задаёт роль и уровень, проходит короткое интервью и получает отчёт с сильными сторонами и точечными рекомендациями.

![React](https://img.shields.io/badge/React-19-20232a?logo=react) ![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript&logoColor=white) ![Vite](https://img.shields.io/badge/Vite-7-646cff?logo=vite&logoColor=white)

## Возможности MVP

- персонализация по роли и уровню;
- четыре вопроса по опыту и командной работе;
- подсказки и демонстрационный ответ;
- итоговая оценка по четырём критериям;
- рекомендации и печатная версия отчёта;
- адаптивный интерфейс без обязательной регистрации.

Сейчас анализ работает в демонстрационном режиме. Следующий продуктовый этап — подключение LLM через серверный API, авторизация и сохранение истории интервью.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm run lint
npm run build
```

## Продуктовая модель

Целевая аудитория первого релиза — junior/middle IT-специалисты. Бесплатный тариф даёт одну тренировку в месяц, Pro — персональные интервью, голосовой режим и историю прогресса.
